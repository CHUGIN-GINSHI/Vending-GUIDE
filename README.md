# 自販機Bot 説明書

駐銀 自販機Bot を自分のサーバーに設置する会員向けの手順書です。

- 公開先: GitHub Pages（`index.html` 1枚の静的サイト）
- 更新: `index.html` を編集して push すると数分で反映されます

## ここに置いてよいもの

- 説明書の本文と、その中で使う画像

## ここに置いてはいけないもの

**このリポジトリは公開されます。** 次のものは絶対に入れないでください。

- `.env` / トークン / パスワード
- ラズパイの構成情報（IP・ホスト名・netns 構成・sudoers）
- 会員の Discord ID や取引の記録

運用側のドキュメントは `ラズパイ管理` リポジトリに置き、こちらには持ち込みません。
